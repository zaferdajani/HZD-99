# App Review notes (Apple / Google)

- **Demo login:** none needed. The game has no accounts or sign-in; reviewers can press Play immediately. No demo-account seed script was added because there is no backend (no Supabase) in this repo.
- **Features:** offline single-player metroidvania (CLAWBYTE / NOSTOS), keyboard, gamepad and touch controls.
- **In-app purchases:** none. No payments, subscriptions or external checkout.
- **Account deletion:** no accounts exist; progress is stored on-device only. Explained at `delete-account.html` (public URL for Google Play's data-deletion field): https://zaferdajani.github.io/HZD-99/delete-account.html
- **User-generated content:** none (no chat, posts, sharing), so no report/block/moderation is needed.
- **Privacy / Terms / Support:** `privacy.html`, `terms.html`, `support.html`; also reachable in-game from Pause → "Privacy, Terms & Support".
- **Screenshots** submitted to the stores must be captured from the real running app/build, not mock-ups (Apple guideline 2.3.3 / reason 7).
