# Character reference plates

Rendered straight from the shipped build — these are the actual characters, not
concept art. Attach the matching plate as an **image reference** on every video
generation, alongside the text prompt from `../INTRO_PRODUCTION_BIBLE.md`.

Each plate is 1200 × 900 on a flat neutral ground (`#141C26`) so the subject
separates cleanly.

> of the camera, the action and the mood — the plate is only there to keep the
> character on-model across twelve separately generated clips.
