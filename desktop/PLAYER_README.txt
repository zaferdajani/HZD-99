CLAWBYTE — Windows x64 desktop playtest

1. Extract the entire downloaded ZIP into a folder you can write to.
2. Open CLAWBYTE.exe in the extracted folder.
3. Keep the other files and folders beside the executable. The .exe alone
   is not the game. No Node.js installation or browser is needed to play.

The game, music and videos are bundled for offline play.
Use the game's Controls screen for keyboard/controller bindings.
F11 toggles fullscreen. Escape opens the game's pause/back controls.
Close the window or use Alt+F4 to quit.

This is an unsigned development playtest, not a signed commercial release.
Windows may warn about an unknown publisher. Do not disable security tools.
Only use builds from the project owner and verify the source/build identity.

build-info.json identifies the source commit, runtime and packaged game hashes.
SHA256SUMS.txt lists SHA-256 hashes of all other files in this folder.
Keep Electron's LICENSE and LICENSES.chromium.html with redistributed builds.

Saves belong to this desktop application, not the web-browser version.
Do not delete the application's user-data folder when replacing the build.

Report a problem with: source commit from build-info.json, Windows version,
CPU/GPU, keyboard or controller model, room name, and reproduction steps.
An executable build is not a certification of Steam release readiness.
